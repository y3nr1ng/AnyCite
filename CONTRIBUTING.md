# Contributing

Any | Cite uses GitHub Flow. Keep `main` deployable and make changes through
short-lived branches and pull requests.

## Workflow

1. Update your local `main` branch.
2. Create a branch such as `feature/add-source-type` or `fix/doi-detection`.
3. Make focused commits and run `npm run check`.
4. Push the branch and open a pull request against `main`.
5. Merge after the validation check passes.

Every push to `main` triggers the GitHub Pages deployment workflow.
